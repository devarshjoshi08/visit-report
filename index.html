Schools missing from School Details

Mapped schools with no column in the report

Everything is counted from the master sheet — Daily Activity tracker 01 Oct, the tab the form writes into. The school code comes from the brackets in School Code and Name, so the sheet's own helper column is not used. School Details is read only to look up each school's state and project.

How a day is counted: one school counts once per day, however many people logged a visit to it. A school lands in a column when its state matches and the column's project is All or matches that school's po.name. This is the same rule the Report tab uses.

Average %Visits uses the Report tab's own formula: visits in the period ÷ (Total SS × days × 6/7). Total SS starts from the values in the Report tab as of 11 Sep 2026; edit any of them in the table and the change is remembered on this device.

Log rows with no school in brackets (project calls, leave, and so on) are skipped, and so are school codes that are missing from School Details — both are counted for you above the table.
